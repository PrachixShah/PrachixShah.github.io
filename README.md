# PrachixShah.github.io

Personal site + portfolio for Prachi Shah. Plain hand-edited HTML, one stylesheet,
no build step, served by GitHub Pages at https://PrachixShah.github.io.

## Pages
- `index.html` — home + about
- `projects.html` — lab & project write-ups
- `resume.html` — résumé (drop the PDF at `assets/Prachi_Shah_Resume.pdf`)
- `log.html` — dated entries
- `bucketlist.html` — running list
- `photos.html` — photo grids (add images to `assets/img/`)
- `ethos.html` — personal "Notes App" (its own granola palette)

## Editing
Every repeating element is a copy-paste block with a comment above it.
The nav is duplicated in each page's `<header>` — update all of them when adding a page.
Colours for the main site live at the top of `assets/style.css`; the Ethos page
carries its own palette inline in its `<style>` block.
